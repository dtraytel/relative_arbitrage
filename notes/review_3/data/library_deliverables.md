# Library deliverables advertised by each ROOT description

One agent per library session mapped every deliverable its ROOT description (and document abstract) advertises to the facts that realise it, verified by grep. These are roots in `roots.txt`. "Undelivered" lists advertised claims with no corresponding theorem: each must either be proved or have its description corrected (plan phase 8).
